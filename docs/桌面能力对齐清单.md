## P0

### P0-1 `get-app-path` 语义漂移 —— 状态：已完成

- **证据**：原版 `api.js:332` 返回 `app.getAppPath()`（应用根目录）；Tauri `bridge.js:73` 原先返回 `app_data_path`（数据目录）
- **使用方**：`AiDoubaoDrawer.vue:93`、`fullscreenOverlay.vue:281`、`genericMicroAppIpcBridge.js`（microApp 资源根路径）
- **影响**：AI 抽屉 / microApp 用该路径拼资源（`_plugins/<id>/dist/index.html`），现在指到 `%LOCALAPPDATA%\cn.coolma.tauri`，找不到应用自带资源
- **方案**：Rust 新增 `app_root_path` 命令（release 取 `current_exe()` 所在目录；dev 取 `src-tauri` 的上一级即打包目录），bridge 的 `get-app-path` 切到该命令
- **验收**：`ipcRenderer.invoke('get-app-path')` 返回 exe 所在目录；dev 模式返回 `desktop-vue2-tauri`
- **落地**（`2d85931b` 之后）：`main.rs` 新增 `app_root_path` + `app_root_from_exe` 纯函数与 4 个单测；`bridge.js:73` 换命令。注意：原版 dev 返回仓库根、Tauri dev 返回打包目录，属构建方式差异，已在单测里钉住

## P1

### P1-1 数据库写放大（sql.js 全量快照） —— 状态：待办

- **证据**：`src/desktop/database/index.js:264-278` 每条写命令都 `db.export()` 整库序列化 + 整文件落盘；原版为 better-sqlite3 增量写
- **现状**：当前库 5.8 MB，等于每改一篇笔记写 5.8 MB；库变大后内存与写放大会同步放大
- **方案 A（推荐）**：Rust 侧 `rusqlite` 代理，前端保留 `db:*` 通道语义，SQL 走 Rust（接近原版形态）
- **方案 B（过渡）**：仍用 sql.js，但写入合批（如 300ms debounce）+ 退出前强制 flush
- **验收**：单次编辑不再整库写盘；库 >50 MB 时编辑不卡；异常退出最多丢合批窗口内的写入

### P1-2 safeStorage v1 遗留密文 —— 状态：待办

- **证据**：原版 `electron-main.js:67-90` 有 CryptoJS 旧版解密分支；Tauri `credential.js` 只走系统凭据库，旧密文返回空串
- **影响**：从 Electron 版迁移过来的用户，AI 模型 API Key 读不出来，需要重填
- **方案**：迁移路径上检测 v1 密文（`version !== 2`）→ 用原版机器派生密钥算法解一次 → 转存系统凭据库；解不出则提示重填
- **验收**：用一份 Electron 版 `memocast.db` 跑起来，AI 模型配置直接可用

### P1-3 `file://` 资源覆盖面 —— 状态：待办

- **证据**：原版 `electron-main.js:3932` 用 `interceptFileProtocol('file')` 透传任意本地路径；Tauri `wiz_resources.rs` 仅服务 `kb/doc/name` 三段缓存
- **影响**：笔记里引用缓存目录之外的本地图片/附件会 404
- **方案**：`coolma-resource` 增加 `local/` 前缀 + 白名单（笔记资源目录、themes、temp），**不做**任意路径透传（避免把本地文件读取能力暴露给渲染层）
- **验收**：含本地图片的笔记在预览/导出里图片可见；白名单外路径返回 403

## P2

### P2-1 崩溃提示缺失 —— 状态：待办

- **证据**：原版 `electron-main.js:3863` 用 `electron-unhandled` 弹窗 + 一键开 GitHub issue；Tauri 只有 `logs/<年>/<月>/main.log` 与 Rust panic hook
- **方案**：启动时检查上次异常退出的标记文件（正常退出清除），命中则在前端提示"上次异常退出，查看日志"，并复用 `open_log_file`
- **验收**：人为触发 panic 后重启，界面有提示且能一键定位日志

### P2-2 快捷键表补全 —— 状态：待办

- **证据**：`src/desktop/shortcutTable.js` 缺 `edit.cut/copy/paste` 角色与 `view.devtool` 加速键
- **说明**：Ctrl+C/V 由 WebView 原生处理，功能可用，只是与原版菜单表不完全一致
- **方案**：补齐 4 条映射；devtool 仅在 debug 构建注册
- **验收**：快捷键表与原版 `menu/templates/*` 的 accelerator 一一对应

- **系统主题跟随**：原版 `nativeTheme.shouldUseDarkColors` 只用于清 `DevTools Extensions`（`electron-main.js:3874-3884`），无 UI 语义
