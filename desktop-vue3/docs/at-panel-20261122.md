# @ 快捷插入面板视觉修复（2026-11-22）

验收：1123×748 浏览器，文件夹视图，编辑器正文中手动唤起 Muya `quickInsert`。

## 现象

面板能生成 6 个分组、约 380×280 的内容，但外框完全透明：
- 无白色卡片背景；
- 无 `--floatShadow` 阴影；
- 分组标题、图标边框、选中态颜色都拿不到主题变量；
- 面板与白色正文粘在一起，只能靠文字位置判断边界。

## 根因

Muya 的 `.ag-float-wrapper` 由 `BaseFloat` 直接 `document.body.appendChild`，不在 `.libs-muya-host` 内。

v3 把 Muya 变量全部挂在 `.libs-muya-host.libs-muya-theme-light`，因此浮层读取 `--floatBgColor / --floatShadow / --themeColor / --editorColor / --iconColor` 时全部为空：

```
background-color: var(--floatBgColor)  → transparent
box-shadow: var(--floatShadow)         → none
border-color: var(--floatBorderColor)  → 无效
```

v2 的 `muya.css` 把这些变量放在 `:root`，所以同样挂 body 的浮层能拿到值。这是 v3 变量作用域收窄后引入的回归，不是 quickInsert 自身 CSS 缺失。

## 改动

在 `desktop-vue3/frontend/src/styles/index.css` 给 `.ag-float-wrapper` 补一份与 v2 `:root` 相同的浮层变量：

- `--themeColor: rgba(64,158,255,1)`
- `--editorColor: rgba(0,0,0,.7)`、`--editorColor50`
- `--iconColor: #6b737b`
- `--floatBgColor: #fff`
- `--floatHoverColor: rgba(0,0,0,.04)`
- `--floatBorderColor: rgba(0,0,0,.1)`
- `--floatShadow` 使用 v2 的三层阴影
- 暗色在 `html.dark .ag-float-wrapper` 下覆盖为 `#232a36` 等值

这样同时覆盖 @ 面板、表格选择器、链接工具条、emoji picker 等所有 Muya 浮层。

## 复验

- 面板外框 `background-color: rgb(255,255,255)`；
- `box-shadow` 为三层 v2 阴影，不再是 `none`；
- 面板尺寸 380×280，位置 `x=657, y=299`，完整落在 1123×748 视口内；
- 标题颜色 `rgba(0,0,0,.7)`；
- 图标容器 28×28，边框恢复可见；
- 选中项蓝框与浅底恢复。

证据：
- `docs/at-panel-20261122.png`：修复前后并排图；
- `docs/at-panel-20261122-after.png`：修复后 1123×748 全屏图。

## 仍未对齐

- 笔记项图标是 v3 provider 生成的 64×64 SVG 蓝底字块，经 v2 的 16×16、`opacity:.5` 规则缩放后字符偏小；v2 的 Rune/Echo icon 走的是同一套 16×16 规则，但数据来源不同，尚未逐项对照。
- 面板分组标题、列数、最大高度直接沿用 Muya 原 CSS（380px、280px、`--quick-insert-columns`），本轮没有改动。
