# P1 工程骨架

> 状态：**P1 已完成（含 Windows 安装包验证）**。
> 目标：一个能启动、能打包、没有业务数据的 Coolma Vue3 壳。

## 1. 范围

P1 只验证：

- electron-egg TS 模板派生；
- 安全窗口：`contextIsolation` / `sandbox` / 无 Node integration；
- preload 白名单：只暴露 `window.coolma.invoke/on`；
- typed IPC：channel / contract / zod；
- Element Plus + Pinia + Vue Router + vue-i18n + **enum-plus**；
- 三栏 Element Plus 壳与设置页（`ElSplitter` 可拖拽分隔）；
- 主题、语言、应用信息与 IPC 状态展示。

**不包含**：SQLite、真实笔记、Muya、Rune/Echo、AI、同步、博客、微应用、自动更新。

### 3.1 三栏 Splitpanes

三栏布局使用 `splitpanes@4`（Vue 3），不是 Element Plus 的 `ElSplitter`，也不是 Quasar。

- 左侧栏：`size=18`，`min-size=14`，`max-size=25`
- 笔记列表：`size=27`，`min-size=20`，`max-size=40`
- 编辑区：`size=55`

三个 pane 的 `size` 必须**显式加起来等于 100**。只给前两个、让第三个自动占剩余时，
splitpanes 在 Muya 这种宽内容下会算出异常宽度；显式 18/27/55 后稳定为 226 / 339 / 691。

已验证：拖拽分隔条后三栏宽度变化，总分栏宽度保持；页面无横向溢出。

### 3.2 索引模式

侧栏保留三档索引，不允许因为布局调整而删掉：

- **文件夹**：按 `notes.category` / `local_categories` 筛选
- **标签**：按 `tags` / `note_tags` 筛选
- **时间**：今天 / 昨天 / 本周 / 更早，后续在同一模式内切日历

当前实现用 `IndexModeEnum`（enum-plus）驱动，模式写入
`localStorage['coolma.indexMode']`；切换模式会清空跨模式筛选。P3 接真实
`categories:list` / `tags:list` / `notes:list` 后保留同一交互。

## 4. enum-plus 约定

- 共享字典放 `electron/shared/enums/`；
- `label` 存 i18n key，组件里 `t(item.label)`；
- Element Plus 的 radio / select 用 `.items` 驱动；
- P1 已接入 `AppThemeEnum`、`AppLocaleEnum`、`BootStatusEnum`、`IndexModeEnum`；
- 后续业务枚举不再写裸字符串联合或原生 `enum`。

示例：

```ts
export const AppThemeEnum = Enum({
  Light: { value: 'light', label: 'settings.light', icon: 'Sunny' },
  Dark: { value: 'dark', label: 'settings.dark', icon: 'Moon' },
});
```

## 5. 本地命令

```powershell
pnpm install

pnpm typecheck
pnpm dev
pnpm build
pnpm build-w
```

开发模式：

- Vite：`http://127.0.0.1:8081`（Vue2 使用 `8080`）
- Electron：`electron . --env=local`
- 主进程 TS 编译到 `public/electron/`
- 前端构建输出 `frontend/dist/`，再移动到 `public/dist/`

> 如果在 Cursor / VS Code 终端里启动，先移除 `ELECTRON_RUN_AS_NODE=1`，
> 否则 Electron 会按 Node 运行，报 `electronApp.getAppPath` 为 undefined。
>
> ```powershell
> Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
> pnpm dev
> ```
