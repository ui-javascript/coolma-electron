# 三视图视觉对齐（2026-11-22）

对照基线：`desktop-vue2` 当前源码，以及 `README.md` 中 1123×748 原版截图。
验收尺寸：1123×748 浏览器渲染；生产前端已重新构建。

## 本轮改动

1. 日历
   - 头部改为单行：日期筛选、时间依据下拉、月份选择器并排。
   - 用 `el-date-picker type="month"` 替代左右箭头，宽度 112px；切月沿用当前日，月末自动收窄。
   - 去掉单元格网格线，仅保留表头分隔线；格子六行随容器高度自适应。
   - 选中态改为日期数字 24×22 蓝色方块，格子本身透明，圆点保持蓝色。
   - 月份选择器监听 `@update:model-value`，修复“能选月份但值不更新”的单向绑定问题。
2. 标签矩形图
   - 外层增加 `.tag-treemap-shell`，四周 10px 留白；ECharts 容器改为填满内层。
3. 笔记卡片
   - 标题取消单行省略，允许自然换行（两行）；同步图标回到标题后侧。
4. 根目录文案
   - 列表底部与根目录笔记分类统一显示“我的笔记”，不再出现“全部笔记”。
