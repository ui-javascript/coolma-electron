# Muya 对照样例

这里的正文在两个模板中保持一致。可逐段比较默认渲染，也可将本文件用作 AST 回归输入。

## 行内节点

这一行混合 **粗体与 *斜体***、~~删除~~、==标记==、H~2~O、x^3^、[相关页面](./markdown.md) 和 `` `literal` ``。脚注引用在标点前[^mixed]。

分隔符转义：\*不是强调\*、\~不是删除线\~、\$100。代码中的 `==原样==、$x$、[链接](./index.md)` 不应被二次解析。

## 块级混排

> 带列表的引用：
>
> - [x] 已解析 **嵌套行内节点**
> - [ ] 还未解析 `代码`

| 单元格 | 期望 |
| --- | --- |
| `a\|b` | 单元格内的竖线不新增一列 |
| ==标记== 和 $x_1$ | 行内扩展可以出现在表格中 |

独立公式：

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
$$

## 保持原样的源码

下面的 Markdown 故意放在围栏里，渲染结果应展示源码，而不是生成卡片、公式或脚注。

```md
::: note
**这里的星号**和 $x$ 应保持原样。
:::

[^literal]: 这段不应生成脚注。
```

[^mixed]: 注释正文包含 [站内链接](./index.md) 与 `\*`。
